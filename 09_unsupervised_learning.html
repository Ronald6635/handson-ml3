前言

無監督學習是機器學習的重要分支，不需要標籤資料即可從資料中發現模式。本教學將帶您深入了解聚類與降維的核心技術。

重點摘要

  • K-Means：基於距離的聚類算法，適用於球形聚類
  • DBSCAN：密度基於聚類，能處理任意形狀的聚類
  • PCA：線性降維技術，保留最大方差
  • t-SNE：非線性降維，適合視覺化高維資料

聚類算法介紹

聚類算法將相似資料點分組，常見應用包括客戶分群、影像分割等。

K-Means 聚類算法

K-Means 是最常見的聚類算法之一，其目標是最小化聚類內距離的平方和。

基本使用

from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

# 產生測試資料
X, y = make_blobs(n_samples=2000, centers=5, random_state=7)

# 建立 K-Means 模型
kmeans = KMeans(n_clusters=5, n_init=10, random_state=42)
y_pred = kmeans.fit_predict(X)

print(f"聚類中心: {kmeans.cluster_centers_}")

預測新資料點

X_new = np.array([[0, 2], [3, 2]])
predictions = kmeans.predict(X_new)
distances = kmeans.transform(X_new)

DBSCAN 密度聚類

DBSCAN 基於密度定義聚類，能發現任意形狀的聚類並識別雜訊點。

from sklearn.cluster import DBSCAN
from sklearn.datasets import load_iris

iris = load_iris()
X = iris.data[:, :2]

dbscan = DBSCAN(eps=0.3, min_samples=5)
y_pred = dbscan.fit_predict(X)

降維技術

降維技術將高維資料投影到低維空間，常用於視覺化與特徵提取。

主成分分析 (PCA)

PCA 通過線性變換找到資料的最大方差方向。

from sklearn.decomposition import PCA

pca = PCA(n_components=0.95)
X_pca = pca.fit_transform(X)

print(f"解釋方差比例: {pca.explained_variance_ratio_}")

t-SNE 視覺化

t-SNE 是一種非線性降維技術，特別適合高維資料的視覺化。

from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, random_state=42)
X_tsne = tsne.fit_transform(X_sample)
