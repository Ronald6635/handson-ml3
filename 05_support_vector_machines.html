🐍 支持向量機 (SVM) 完整教學

💡 關鍵要點

  • 核心思想: SVM 的目標是找到一個能將不同類別的數據點分隔開的最優超平面（decision boundary），並使得這個超平面到最近的數據點（支持向量）的距離（margin）最大化。
  • 硬邊界 vs. 軟邊界: 硬邊界 (Hard Margin) 要求所有數據點都必須被完美分類；軟邊界 (Soft Margin) 則允許一些數據點被錯誤分類或落在邊界內，以換取更好的泛化能力，由超參數 C 控制。
  • 特徵縮放的重要性: SVM 對特徵的尺度非常敏感。在訓練前，必須對數據進行標準化 (Standardization)，否則尺度較大的特徵會主導模型，導致次優的決策邊界。
  • 核技巧 (Kernel Trick): 對於非線性數據，SVM 使用核技巧（如多項式核、高斯 RBF 核）將數據隱式地映射到更高維度的空間，從而在這個高維空間中找到一個線性的分隔超平面，而無需實際計算高維特徵，極大地提高了計算效率。
  • 應用於迴歸: SVM 不僅能用於分類，也能用於迴歸 (SVR)。其目標是讓盡可能多的數據點落在一個由超參數 epsilon (ε) 控制的「街道」內。

🎯 前言：為何選擇支持向量機？

支持向量機 (Support Vector Machine, SVM) 是一種功能強大且用途廣泛的機器學習模型，能夠執行線性或非線性的分類、迴歸，甚至是異常點偵測任務。它在中小規模且複雜的數據集上表現尤其出色。

實際應用場景:

  • 圖像分類: SVM 曾是圖像識別領域的領先技術，例如手寫數字辨識、人臉偵測。
  • 生物資訊學: 用於基因分類、蛋白質分類等。
  • 文本分類: 如垃圾郵件過濾、情感分析。
  • 金融預測: 預測股價走勢或信用風險評估。

本教學將帶您從 SVM 的基本概念——最大化分類邊界開始，逐步深入到處理非線性數據的核技巧，最後探討其在迴歸問題上的應用。

線性 SVM 分類

🐍 大間隔分類 (Large Margin Classification)

SVM 的核心思想是找到一個決策邊界，這個邊界不僅能分開兩個類別，而且能讓兩個類別之間「街道」的寬度最大化。這條「街道」的邊緣由最靠近決策邊界的數據點決定，這些點被稱為「支持向量」(Support Vectors)。

下圖展示了這個概念：左圖顯示了多個可能的決策邊界，但它們的分類間隔 (margin) 並非最佳。右圖則顯示了 SVM 找到的最佳解——一條具有最大間隔的決策邊界。

# 載入鳶尾花數據集並選取兩個特徵與兩個類別
import numpy as np
from sklearn import datasets
from sklearn.svm import SVC

iris = datasets.load_iris(as_frame=True)
X = iris.data[["petal length (cm)", "petal width (cm)"]].values
y = iris.target

setosa_or_versicolor = (y == 0) | (y == 1)
X = X[setosa_or_versicolor]
y = y[setosa_or_versicolor]

# 訓練一個硬邊界 SVM 模型
# C 設為一個極大值，模擬硬邊界分類
svm_clf = SVC(kernel="linear", C=1e9)
svm_clf.fit(X, y)

✅ 程式碼逐行解析

  1. import: 導入必要的函式庫，包括 numpy、datasets 和 SVC。
  2. load_iris: 載入 Scikit-Learn 內建的鳶尾花數據集。
  3. X = iris.data[...]: 從數據集中選取「花瓣長度」和「花瓣寬度」作為我們的特徵。
  4. setosa_or_versicolor = ...: 創建一個布林遮罩，只選擇 'setosa' (y=0) 和 'versicolor' (y=1) 這兩個類別。
  5. X = X[...], y = y[...]: 應用遮罩，篩選出我們需要的數據。
  6. svm_clf = SVC(...): 創建一個 SVM 分類器實例。
    • kernel="linear": 指定使用線性核，因為我們正在進行線性分類。
    • C=1e9: C 是正規化參數。這裡將它設為一個非常大的數，是為了模擬「硬邊界」分類，即不允許任何分類錯誤。
  7. svm_clf.fit(X, y): 使用準備好的數據訓練 SVM 模型。

🐍 特徵縮放的重要性

SVM 對特徵的尺度（scale）非常敏感。如果不同特徵的數值範圍差異很大，SVM 的決策邊界會被數值範圍較大的特徵所主導，導致模型性能下降。

下圖展示了特徵縮放的重要性：

  • 左圖 (未縮放): x1 特徵的範圍遠大於 x0，導致決策邊界幾乎是水平的，忽略了 x0 的影響。
  • 右圖 (已縮放): 使用 StandardScaler 進行特徵縮放後，兩個特徵的尺度變得相似，SVM 能夠找到一個更平衡、更優的決策邊界。
from sklearn.preprocessing import StandardScaler

# 未縮放的數據
Xs = np.array([[1, 50], [5, 20], [3, 80], [5, 60]]).astype(np.float64)
ys = np.array([0, 0, 1, 1])
svm_clf_unscaled = SVC(kernel="linear", C=100).fit(Xs, ys)

# 進行特徵縮放
scaler = StandardScaler()
X_scaled = scaler.fit_transform(Xs)
svm_clf_scaled = SVC(kernel="linear", C=100).fit(X_scaled, ys)

✅ 程式碼逐行解析

  1. Xs, ys: 創建一個簡單的數據集，其中特徵 x1 的數值範圍 (20-80) 遠大於 x0 (1-5)。
  2. svm_clf_unscaled.fit(Xs, ys): 在未縮放的數據上訓練一個 SVM 模型。
  3. scaler = StandardScaler(): 創建一個 StandardScaler 物件，它會將特徵標準化，使其平均值為 0，標準差為 1。
  4. X_scaled = scaler.fit_transform(Xs): 對數據 Xs 進行擬合和轉換，得到縮放後的數據 X_scaled。
  5. svm_clf_scaled.fit(X_scaled, ys): 在縮放後的數據上訓練一個新的 SVM 模型。

💡 最佳實踐: 在使用 SVM 之前，務必對數據進行特徵縮放。StandardScaler 是最常用的方法之一。將縮放器和分類器打包在一個 Pipeline 中是個好習慣。

🐍 軟間隔分類 (Soft Margin Classification)

在現實世界的數據中，數據點很少是完美線性可分的，而且常含有噪點。如果堅持使用硬邊界分類，模型可能會因為一兩個異常點而產生很差的決策邊界，或者根本找不到解。

軟間隔分類允許模型在一定程度上「犯錯」。它在「保持街道寬度」和「限制間隔違例 (margin violations)」之間尋求一個平衡。這個平衡由超參數 C 控制：

  • 較小的 C: 產生較寬的街道，但允許較多的間隔違例。這對數據的噪點有較高的容忍度，正規化程度較高，有助於避免過擬合。
  • 較大的 C: 產生較窄的街道，盡力減少間隔違例。模型會更努力地去擬合每一個數據點，正規化程度較低，可能會導致過擬合。

下圖展示了不同 C 值對決策邊界的影響。左圖 C=1 的模型有更寬的間隔，而右圖 C=100 的模型間隔較窄，更緊密地擬合了數據。

from sklearn.pipeline import make_pipeline
from sklearn.svm import LinearSVC

# 建立一個分類 Iris virginica 的二元分類問題
iris = load_iris(as_frame=True)
X = iris.data[["petal length (cm)", "petal width (cm)"]].values
y = (iris.target == 2)  # True for Iris virginica, False for others

# 建立一個包含特徵縮放和 LinearSVC 的 pipeline
# C=1, 正規化程度較高
svm_clf1 = make_pipeline(StandardScaler(),
                         LinearSVC(C=1, dual=True, random_state=42))
svm_clf1.fit(X, y)

# C=100, 正規化程度較低
svm_clf2 = make_pipeline(StandardScaler(),
                         LinearSVC(C=100, dual=True, random_state=42))
svm_clf2.fit(X, y)

✅ 程式碼逐行解析

  1. y = (iris.target == 2): 創建一個二元目標變數，判斷鳶尾花是否為 'virginica'。
  2. make_pipeline(...): 創建一個 Scikit-Learn Pipeline，它會將多個處理步驟串聯起來。這可以確保在訓練和預測時，數據都經過相同的轉換流程。
  3. StandardScaler(): Pipeline 的第一步，對數據進行標準化。
  4. LinearSVC(...): Pipeline 的第二步，訓練一個線性 SVM 分類器。
    • C=1 和 C=100: 分別設定了不同的正規化強度。
    • dual=True: 處理 n_samples > n_features 的情況，是 LinearSVC 的一個技術性參數。
  5. fit(X, y): 訓練整個 pipeline。數據會先經過 StandardScaler 處理，然後再傳遞給 LinearSVC 進行訓練。

🔄 非線性 SVM 分類

現實中的數據集大多不是線性可分的。處理這種問題有兩種主要方法：

  1. 添加多項式特徵: 手動為數據添加新的特徵（例如，將 x1 轉換為 x1, x1^2），然後在新的特徵空間中使用線性 SVM。
  2. 使用核技巧: 這是 SVM 更為強大和高效的方法。

🐍 多項式核 (Polynomial Kernel)

手動添加多項式特徵在低維度時是可行的，但當特徵維度和多項式次數增加時，會導致特徵數量爆炸性增長，使得模型訓練變得非常緩慢。

核技巧 (Kernel Trick) 是一個絕妙的數學技巧，它可以在不實際創建高維特徵的情況下，得到與在高維特徵空間中訓練線性 SVM 完全相同的結果。

SVC 類別內建了多種核函數，包括多項式核。

from sklearn.datasets import make_moons

X, y = make_moons(n_samples=100, noise=0.15, random_state=42)

# 方法一：手動添加多項式特徵 + 線性 SVM
from sklearn.preprocessing import PolynomialFeatures
polynomial_svm_clf = make_pipeline(
    PolynomialFeatures(degree=3),
    StandardScaler(),
    LinearSVC(C=10, max_iter=10_000, dual=True, random_state=42)
)
polynomial_svm_clf.fit(X, y)

# 方法二：使用多項式核的 SVC
poly_kernel_svm_clf = make_pipeline(
    StandardScaler(),
    SVC(kernel="poly", degree=3, coef0=1, C=5)
)
poly_kernel_svm_clf.fit(X, y)

✅ 程式碼逐行解析

  1. make_moons: 生成一個非線性的「月亮」形狀數據集，常用於測試非線性分類算法。
  2. PolynomialFeatures(degree=3): 這是一個特徵轉換器，它會生成所有小於等於 3 次的多項式組合特徵。
  3. SVC(kernel="poly", ...): 創建一個使用多項式核的 SVM 分類器。
    • kernel="poly": 指定使用多項式核。
    • degree=3: 指定多項式的次數。
    • coef0=1: 控制模型受高次項與低次項影響的程度。
    • C=5: 正規化參數。

🎯 重點摘要: 使用 SVC(kernel="poly") 通常比手動組合 PolynomialFeatures 和 LinearSVC 更高效，特別是在高次數時。你需要透過交叉驗證來調整 degree, coef0, 和 C 等超參數。

🐍 相似性特徵

另一種處理非線性問題的思路是，根據數據點與特定「地標」(landmark) 的相似度來添加新特徵。一個常用的相似度函數是高斯徑向基函數 (Gaussian Radial Basis Function, RBF):

$$ \phi_{\gamma}(\mathbf{x}, \boldsymbol{\ell}) = \exp(-\gamma \|\mathbf{x} - \boldsymbol{\ell}\|^2) $$

這個函數的值域在 0 (距離地標很遠) 到 1 (與地標重合) 之間。通過計算每個數據點到多個地標的相似度，我們可以將數據轉換到一個新的特徵空間，在這個空間中數據可能就變得線性可分了。

🐍 高斯 RBF 核 (Gaussian RBF Kernel)

與多項式特徵一樣，手動選擇地標並計算相似性特徵在實務上是困難且低效的。幸運的是，RBF 核同樣可以透過核技巧來實現，而無需實際計算任何相似性特徵。

RBF 核是 SVM 中最常用、也是預設的核函數。它非常強大，能夠處理各種複雜的非線性數據。

# 使用高斯 RBF 核的 SVC
rbf_kernel_svm_clf = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", gamma=5, C=0.001)
)
rbf_kernel_svm_clf.fit(X, y)

✅ 程式碼逐行解析

  1. SVC(kernel="rbf", ...): 創建一個使用 RBF 核的 SVM 分類器。
    • kernel="rbf": 指定使用高斯 RBF 核。
    • gamma: 控制 RBF 函數「鐘形曲線」的寬度。可以看作是一個正規化參數。
      • 較小的 gamma: 產生較平滑、寬泛的決策邊界（高正規化，可能導致欠擬合）。
      • 較大的 gamma: 產生更複雜、更不規則的決策邊界，緊密貼合訓練數據（低正規化，可能導致過擬合）。
    • C: 與線性 SVM 中的 C 意義相同，控制間隔違例的懲罰。

💡 最佳實踐: 當你開始處理一個新的分類問題時，使用 SVC(kernel="rbf") 通常是一個很好的起點。你需要同時對 gamma 和 C 進行超參數調優，以找到最佳的模型。

🚀 SVM 迴歸

SVM 也可以用於迴歸任務 (SVR)。其目標與分類相反：分類是讓街道盡可能寬，而迴歸是讓盡可能多的數據點落在街道內。

  • 街道寬度: 由超參數 epsilon (ε) 控制。落在街道內的數據點不會對模型產生任何影響，因此 SVR 被稱為是「ε-不敏感 (ε-insensitive)」的。
  • 目標: 在限制間隔違例（落在街道外的點）的同時，讓盡可能多的點擬合在街道內。

SVR 同樣支持核技巧，因此可以執行線性和非線性迴歸。

from sklearn.svm import LinearSVR, SVR

# 線性 SVR
np.random.seed(42)
X = 2 * np.random.rand(50, 1)
y = 4 + 3 * X[:, 0] + np.random.randn(50)

svm_reg = make_pipeline(StandardScaler(),
                        LinearSVR(epsilon=0.5, dual=True, random_state=42))
svm_reg.fit(X, y)

# 非線性 SVR (使用多項式核)
np.random.seed(42)
X = 2 * np.random.rand(50, 1) - 1
y = 0.2 + 0.1 * X[:, 0] + 0.5 * X[:, 0] ** 2 + np.random.randn(50) / 10

svm_poly_reg = make_pipeline(StandardScaler(),
                             SVR(kernel="poly", degree=2, C=0.01, epsilon=0.1))
svm_poly_reg.fit(X, y)

✅ 程式碼逐行解析

  1. LinearSVR: 用於線性迴歸的 SVM 模型。
    • epsilon=0.5: 設定了街道寬度的一半。預測誤差小於 0.5 的點不會被懲罰。
  2. SVR: 通用的 SVM 迴歸模型，支持核技巧。
    • kernel="poly": 使用多項式核來擬合非線性數據。
    • degree=2: 多項式次數。
    • C 和 epsilon: 分別是正規化參數和街道寬度參數。

🎯 重點摘要: SVR 的超參數 epsilon 控制了模型的「不敏感區域」。增加 epsilon 會使模型對更多數據點不敏感，從而產生更平滑、正規化程度更高的模型。

💡 深入探討：SVM 的數學原理

  • 決策函數: 線性 SVM 的預測基於決策函數 $s(\mathbf{x}) = \mathbf{w}^\top \mathbf{x} + b$。預測結果為正類的條件是 $s(\mathbf{x}) \ge 0$。
  • 最大化間隔: 最大化間隔等價於最小化權重向量的 L2 範數 $\|\mathbf{w}\|$。這就是為什麼 SVM 的目標函數是最小化 $\frac{1}{2} \|\mathbf{w}\|^2$。較小的權重向量會導致較寬的間隔。
  • Hinge 損失: 對於軟間隔分類，SVM 使用 Hinge 損失函數來懲罰間隔違例。其形式為 $\max(0, 1 - t \cdot s(\mathbf{x}))$，其中 $t$ 是目標類別（-1 或 1）。如果一個點被正確分類且在間隔之外，其損失為 0；否則，損失會隨著它偏離正確位置的距離線性增加。

❓ 常見問題 (FAQ)

Q1: LinearSVC, SVC(kernel="linear"), 和 SGDClassifier(loss="hinge") 有什麼區別？

A1: 這三者都可以用來訓練線性 SVM。

  • LinearSVC: 基於 liblinear 函式庫，專為線性 SVM 優化，速度非常快。它不直接支持核技巧。在樣本數遠大於特徵數時，建議設定 dual=False。
  • SVC(kernel="linear"): 基於 libsvm 函式庫，支持核技巧。當你使用線性核時，它的速度通常比 LinearSVC 慢。
  • SGDClassifier(loss="hinge"): 使用隨機梯度下降 (SGD) 來優化 Hinge 損失，這也等價於訓練一個線性 SVM。它可以處理非常大的數據集（支持線上學習），但對超參數較為敏感，且需要手動調整學習率。

總結: 對於純線性問題，優先選擇 LinearSVC。如果數據集非常大，無法一次性載入內存，則使用 SGDClassifier。如果需要比較線性核與其他核的效果，則使用 SVC。

Q2: 如何為 RBF 核選擇 C 和 gamma？

A2: C 和 gamma 是 SVM 中最重要的兩個超參數，它們共同決定了模型的複雜度和泛化能力。最佳的選擇是使用網格搜索 (GridSearchCV) 或隨機搜索 (RandomizedSearchCV) 結合交叉驗證來系統性地尋找最佳組合。一般來說：

  • 從一個較大的範圍開始搜索，例如 C 在 [0.1, 1, 10, 100]，gamma 在 [0.001, 0.01, 0.1, 1]。
  • 根據搜索結果，在最佳參數周圍進行更精細的搜索。
  • gamma 的一個經驗法則是 1 / (n_features * X.var())，可以作為一個初始的參考值。

Q3: SVM 為什麼對大數據集訓練很慢？

A3: 傳統的 SVM 算法（如 SVC 中使用的 libsvm）的計算複雜度大約在 $O(n_{samples}^2 \cdot n_{features})$ 到 $O(n_{samples}^3 \cdot n_{features})$ 之間。當樣本數量 n_samples 很大時，計算成本會急劇增加。這就是為什麼對於大型數據集，推薦使用 LinearSVC（如果問題是線性的）或 SGDClassifier。

Q4: SVM 如何處理多類別分類？

A4: SVM 本質上是一個二元分類器。Scikit-Learn 中的 SVM 類別會自動使用以下策略之一來處理多類別問題：

  • 一對多 (One-vs-Rest, OvR): 為 K 個類別訓練 K 個分類器。第 i 個分類器負責將類別 i 與所有其他類別分開。預測時，選擇置信度最高的那個分類器對應的類別。LinearSVC 使用此策略。
  • 一對一 (One-vs-One, OvO): 為 K 個類別中的每一對組合訓練一個分類器，總共需要訓練 $K(K-1)/2$ 個分類器。預測時，讓所有分類器進行投票，得票最多的類別即為最終結果。SVC 預設使用此策略，因為它在處理小數據集時更高效。
